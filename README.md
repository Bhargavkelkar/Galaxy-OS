# 🌌 GALAXY OS

A modern, web-based desktop environment inspired by macOS, built for Hack Club's WebOS mission.

## ✨ Features
* **macOS Glassmorphism UI:** Translucent menu bar, dynamic digital clock, space wallpaper, and interactive dock.
* **Interactive Terminal App:** Custom CLI supporting utility and system commands.
* **System Diagnostics:** Hardware monitor displaying status and memory specs.
* **Quick Notes App:** Built-in notepad widget for quick session notes.
* **Draggable Windows:** Move app windows seamlessly around the desktop.

## 🛠️ Tech Stack
* **HTML5**
* **CSS3** (Glassmorphism & Flexbox)
* **JavaScript** (ES6+)

## 💻 Terminal Commands
Open the **Terminal** inside GALAXY OS and try running:
* `help` — List available commands
* `clear` — Clear terminal screen
* `version` — Display OS build version
